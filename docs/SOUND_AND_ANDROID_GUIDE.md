# AlphaRush — Adding Sound & Running on Android

Two how-tos for the current build: wiring in audio files, and getting the game
onto an Android phone. Written for the project exactly as it is now (candy
theme, generated scenes).

---

## Part 1 — Adding Sound

### 1.1 File format & where files go

Use **`.ogg`** files (best quality-per-MB; the APK budget is 35 MB total with
~5 MB for audio). Convert mp3/wav → ogg with [Audacity](https://www.audacityteam.org)
(File → Export → OGG, quality ~5) if needed.

| What | Drop into | Examples |
|---|---|---|
| Background music (loops) | `Assets/Audio/Music/` | `bgm_menu.ogg`, `bgm_game.ogg` |
| Sound effects | `Assets/Audio/SFX/` | `sfx_found.ogg`, `sfx_win.ogg` |

Both folders already exist in the project.

### 1.2 Import settings (once per file, in Unity)

Click a file in the Project window → Inspector:

**SFX** (short clips):
- Load Type: **Decompress On Load**
- Force To Mono: ✅
- Compression Format: Vorbis, Quality ~0.7

**Music** (long loops):
- Load Type: **Streaming**
- Force To Mono: ❌ (keep stereo)
- Compression Format: Vorbis, Quality ~0.6

### 1.3 Which sound effects the game expects

`SoundManager` plays clips from an array **indexed by the `SoundEvent` enum
order** (`Assets/Scripts/Audio/SoundEvent.cs`). One clip per slot, in exactly
this order:

| # | Event | Played when |
|---|---|---|
| 0 | `TAP` | tile press |
| 1 | `SELECT` | drag extends the selection |
| 2 | `FOUND` | word found (pitch rises with combo) |
| 3 | `COMBO` | combo banner shows |
| 4 | `MISS` | invalid selection released |
| 5 | `HINT` | hint used |
| 6 | `PAUSE` | pause opened |
| 7 | `STAR_POP` | each star on the results sheet |
| 8 | `WIN` | level complete (victory confetti moment) |
| 9 | `LOSE` | *currently unused* — the timer counts up with no limit, so the game can't be lost. Leave the slot empty (or fill it for future modes) |
| 10 | `UNLOCK` | topic unlocked **and** the "NEW BEST!" badge on the results sheet |
| 11 | `BUTTON` | any menu button |

You don't need all 12 — empty slots are silently skipped. Start with
`FOUND`, `MISS`, `WIN`, `BUTTON` for the biggest impact.

> ℹ️ **Timer design note:** the in-game timer is a count-up stopwatch, not a
> countdown. Stars are awarded on completion from elapsed time + hints used
> (fast & hint-free = 3★). Leaving mid-level saves the board and freezes the
> clock; returning offers Resume (continues the same time) or Start Over
> (new shuffled board, timer reset). A result that beats your stored best
> (more stars, or same stars faster) triggers the NEW BEST! badge — that's
> the `UNLOCK` sound moment.

Free, license-safe sources: [Kenney.nl audio packs](https://kenney.nl/assets?q=audio)
(CC0), [freesound.org](https://freesound.org) (filter license = CC0),
[Pixabay SFX](https://pixabay.com/sound-effects/).

### 1.4 Wiring the clips (in the Unity Editor)

1. Open `Assets/Scenes/Bootstrap.unity`.
2. Select the **ServicesRoot** object in the Hierarchy.
3. On the **SoundManager** component → expand **Clips** → set size to `12` →
   drag each `.ogg` from `Assets/Audio/SFX/` into its numbered slot
   (order from the table above; leave missing ones empty).
4. Save the scene (**Ctrl+S**).

For background music there is no inspector slot yet — the intended pattern is
one line wherever the music should start. Easiest: ask Claude Code to
"wire bgm_menu.ogg to play on app start", or add to `AppBootstrap.Start()`:

```csharp
var bgm = Resources.Load<AudioClip>("Music/bgm_menu"); // if placed under a Resources folder
ServiceLocator.Music.PlayMusic(bgm);
```

(`MusicManager.PlayMusic(clip)` crossfades; `SetVolume` is already hooked to
the Settings slider.)

> ⚠️ **Heads-up:** `Bootstrap.unity` is regenerated by
> `AlphaRush → Build All (Scenes + Prefabs)`. Rebuilding wipes hand-wired
> inspector slots. If you plan to re-run the builder, tell Claude Code to bake
> the clip wiring into `AlphaRushSceneBuilder.cs` so it survives rebuilds.

### 1.5 Quick test

Enter Play mode from Bootstrap → tap buttons (BUTTON), find a word (FOUND),
release a wrong drag (MISS). The Settings screen's SFX/Music sliders and the
Sound toggle already control everything.

## Part 2 — Running on Android

**Use Unity — you do not need Android Studio.** Unity bundles its own Android
SDK/NDK/JDK when installed with the Android modules, builds the APK itself,
and can install it on your phone over USB in one click. (Android Studio is
only needed if you later export a Gradle project for deep native
customization — not required for this game.)

### 2.1 One-time setup

1. **Unity Hub → Installs → 6000.4.7f1 → ⚙ → Add modules** — make sure these
   are ticked (install if not):
   - ✅ Android Build Support
   - ✅ Android SDK & NDK Tools
   - ✅ OpenJDK
2. **On your phone:**
   - Settings → About phone → tap **Build number** 7× (enables Developer
     options)
   - Settings → Developer options → enable **USB debugging**
3. Connect the phone by USB cable. If the phone shows "Allow USB debugging?",
   tap **Allow**.

### 2.2 Build & run (every time)

1. Open the project in Unity.
2. **File → Build Settings** (or *Build Profiles* in Unity 6):
   - Platform: **Android** — if it isn't already, select it → **Switch
     Platform** (one-time, a few minutes).
   - Scene list should show `Scenes/Bootstrap` (0) and `Scenes/Main` (1) —
     already configured.
   - Texture Compression: **ASTC**.
3. In **Run Device** dropdown pick your phone (press Refresh if empty).
4. Click **Build And Run** → choose `Builds/AlphaRush.apk` (create the
   `Builds` folder when prompted).
5. First build takes 5–15 min (IL2CPP compile). The game launches on the
   phone automatically when done.

### 2.3 Install without the cable dialog (optional)

If you built the APK but want to (re)install manually:

```
"C:\Program Files\Unity\Hub\Editor\6000.4.7f1\Editor\Data\PlaybackEngines\AndroidPlayer\SDK\platform-tools\adb.exe" install -r C:\Github\AlphaRush\Builds\AlphaRush.apk
```

### 2.4 Troubleshooting

| Symptom | Fix |
|---|---|
| App installs but no icon appears (or crashes instantly on tap) | The custom manifest's launcher activity must match Player Settings → Other Settings → **Application Entry Point**. This project uses **GameActivity**, so `Assets/Plugins/Android/AndroidManifest.xml` must declare `com.unity3d.player.UnityPlayerGameActivity` with theme `BaseUnityGameActivityTheme` (already fixed). If you ever switch the entry point to "Activity", change the manifest class back to `com.unity3d.player.UnityPlayerActivity` and drop the theme attribute |
| Phone not in Run Device list | Reconnect USB, confirm the debugging prompt on the phone, try another cable/port |
| "SDK not found" errors | Unity Hub → Installs → Add modules → reinstall Android SDK & NDK Tools |
| Build succeeds but app crashes on open | Connect USB, run `adb logcat -s Unity` and share the log |
| APK too big (> 35 MB) | Re-encode audio at lower quality; check texture compression is ASTC |
| Gradle errors on first build | Usually a stale lock — close Unity, delete `Library/Bee`, reopen, rebuild |

portrait & landscape auto-rotation · VIBRATE permission in
